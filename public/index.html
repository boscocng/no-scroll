nofeed

A personal filter for TikTok and Instagram in Safari. TikTok keeps messages and search and loses its feeds. Instagram keeps everything except Reels.

It needs the free Userscripts app from the App Store. Open it once after installing it.

TikTok

Install the TikTok script
  1. Delete the TikTok app.
  2. In Settings, go to Apps > Safari > Extensions > Userscripts. Turn it on and allow it on tiktok.com, instagram.com and this site.
  3. Tap the install button above. When the script's text appears, tap AA in the address bar, then Userscripts, then Tap to install.
  4. Open the Userscripts popup once after installing or updating.
  5. Switch TikTok to its desktop version, the only one with messages: open tiktok.com, tap the button at the left of the address bar, then Request Desktop Website. Safari remembers this for TikTok.
  6. Open the TikTok launcher, tap Share, then Add to Home Screen. Turn Open as Web App off before you tap Add. The icon opens your messages; Search and Activity are in TikTok's left sidebar.

Instagram

Install the Instagram script
  1. Delete the Instagram app.
  2. In Settings, go to Apps > Safari > Extensions > Userscripts. Turn it on and allow it on tiktok.com, instagram.com and this site.
  3. Tap the install button above. When the script's text appears, tap AA in the address bar, then Userscripts, then Tap to install.
  4. Open the Userscripts popup once after installing or updating.
  5. Open the Instagram launcher, tap Share, then Add to Home Screen. Turn Open as Web App off before you tap Add.

Updates

Updates don't install by themselves. Open the Userscripts popup, tap the Updates icon, tap Check Updates, then Update All.
